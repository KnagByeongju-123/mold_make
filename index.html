01

신규 등록 — 제작 건 개설

[신규 등록] 탭에서 금형번호와 금형명을 입력하고 등록합니다. 고객사·제품명·담당자·납기일은 선택 입력입니다.

  • 등록하면 10 견적 요청 ~ 180 금형 이관까지 17개 공정이 자동 생성됩니다.
  • 10 견적 요청은 자동으로 진행 상태가 되고, 나머지는 대기로 대기합니다.
  • 등록 직후 공정 진행 화면으로 자동 이동합니다.
02

공정 진행 — 상태 처리

[공정 진행] 탭 상단에서 금형을 선택하면 공정 보드가 표시됩니다. 카드 왼쪽 숫자가 공정 번호이고, 오른쪽 버튼으로 상태를 처리합니다. 공정명을 클릭하면 업무 내용·결과물·되돌림 경로가 팝업으로 열립니다.

대기 → 진행. 작업자명을 입력하면 이력에 기록됩니다.
공정 합격 처리. 완료 시각이 기록되고 다음 공정이 자동 개시됩니다.
불합격 처리. 흐름도의 되돌림 경로대로 이전 공정이 자동 재진행되고 NG 횟수가 누적됩니다.

담당 주체(고객사·사내·외주)는 업체마다 다를 수 있어 별도로 구분하지 않습니다. 외주로 진행하는 부품은 아래 03의 부품 관리에서 기록하세요.

03

부품 발주·입출고 관리 (40 ~ 130)

금형설계부터 사상·조립까지(40 · 50 · 60 · 80 · 90 · 100 · 120 · 130) 각 공정 카드 하단의 외주 부품 영역에서 부품 단위로 발주와 입출고를 관리합니다. 원자재 입고와 열처리 완료품 입고는 별도 공정 대신 이 영역의 입고 기록으로 대체합니다.

  • 제목줄을 클릭하면 펼쳐지고, 부품명·치수·가공내용·외주업체를 입력 후 + 추가로 등록합니다.
  • 한번 등록한 부품명·치수·가공내용·업체는 몇 글자만 입력하면 자동완성 목록으로 나타납니다.
  • 발주 → 출고 → 입고 버튼을 순서대로 눌러 날짜를 기록합니다. 오늘 날짜가 기본값이며 수정 가능합니다.
  • 날짜가 기록되면 초록색으로 표시되고, 제목줄에 입고완료 건수가 집계됩니다.
  • 전 부품이 입고되어야 해당 공정을 OK 처리하는 것을 권장합니다.
  • 출력물 체크리스트(SQ 대응): 결과물이 있는 공정 카드에 「출력물 n/m 작성」 영역이 표시됩니다. 작성 완료 시 체크하면 날짜·작성자가 기록되고, 「첨부」로 증빙 사진을 등록합니다. 전 항목 작성 시 완비 표시.
  • 모든 기록은 이력 탭에 「부품」 구분으로 남습니다.
04

NG 되돌림 경로

NG 처리 시 흐름도의 회귀선과 동일하게 이전 공정으로 자동 복귀하며, 해당 공정이 다시 진행 상태가 됩니다. 되돌림 경로는 NG 발생 시 카드 하단에 표시됩니다.

50 금형설계 승인→ 40 금형설계 진행
140 Try-Out→ 120 정밀 가공
150 고객사 SPL 승인→ 140 Try-Out
160 양산처 Try-Out→ 140 Try-Out
05

대시보드 — 전체 현황 확인

[대시보드] 탭에서 진행중·완료·NG 누적·전체 금형 수와 금형별 진행률을 확인합니다.

  • 진행률 바 아래에 현재 공정이 표시됩니다. NG가 있으면 NG 공정이 우선 표시됩니다.
  • 카드를 클릭하면 해당 금형의 공정 진행 화면으로 이동합니다.
  • 카드 우측 ✕는 금형과 그 공정·이력을 함께 삭제합니다. 복구되지 않습니다.
06

완료 처리 및 이력 확인

180 금형 이관까지 전 공정이 OK가 되면 금형 상태가 완료로 자동 전환됩니다.

  • [이력] 탭에서 등록·시작·OK·NG·부품 전 기록을 최근 200건까지 조회합니다.
  • 기록 항목: 일시 / 금형번호 / 공정코드 / 구분 / 내용 / 작업자.
참고
  • 원본 흐름도의 170 중복 항목은 170(조립 — 도색·명판·출하검사)과 175(영업 — SCRAP BOX·금형이력카드)로 분리했습니다.
  • 원본 흐름도의 70(원자재 및 표준품 입고)과 110(열처리 완료품 입고)은 부품 관리의 입고 기록으로 대체하여 공정에서 제외했습니다.
  • 공정 마스터(업무 내용·결과물·담당·되돌림 경로)는 DB의 mm_master 테이블에 있습니다. 공정 문구를 바꾸려면 이 테이블을 수정하세요.
  • [게시판] 탭에서 개선·수정 요청사항을 등록하고 접수/완료 상태를 눌러 전환할 수 있습니다.
  • [제작계획] 탭에서 공정별 계획 시작·완료일을 입력해 금형제작 계획을 수립하고, 실적과 대비합니다. 계획완료일 경과 미완료 공정은 지연 표시되며 엑셀 출력을 지원합니다.
  • [Tryout] 탭에서 차수(1차~양산전)·상태·작업/이슈/계획·사진을 일지로 기록하고, 기간·금형·차수·상태로 필터 조회합니다.
  • [이력] 탭 상단에서 기간·금형·구분으로 필터 조회하고, 조회 결과를 엑셀(CSV)로 출력할 수 있습니다. 각 행의 ✕로 개별 삭제도 가능합니다.
  • 프로그램 진입 시 PIN 4자리로 로그인합니다. 사원 PIN은 [설정] 탭(마스터 비밀번호 필요)에서 등록·삭제하며, 로그인한 사용자 이름이 작업자·작성자에 자동 기록됩니다.
  • 데이터는 Supabase에 저장되며 여러 PC에서 같은 현황을 공유합니다.
