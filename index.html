사용안내 — 금형 제작 흐름도 기준 진행 절차

본 화면은 샘플 데이터로 동작을 확인하는 용도입니다. 아래 순서대로 진행하면 흐름도의 OP10 견적 요청부터 OP180 금형 이관까지 전 공정이 관리됩니다.
01

신규 등록 — 제작 건 개설

[신규 등록] 탭에서 금형번호와 금형명을 입력하고 등록합니다. 고객사·제품명·담당자·납기일은 선택 입력입니다.

  • 등록하면 OP10 견적 요청 ~ OP180 금형 이관까지 17개 공정이 자동 생성됩니다.
  • OP10은 자동으로 진행 상태가 되고, 나머지는 대기로 대기합니다.
  • 등록 직후 공정 진행 화면으로 자동 이동합니다.
02

공정 진행 — 상태 처리

[공정 진행] 탭 상단에서 금형을 선택하면 흐름도 형태의 공정 보드가 표시됩니다. 각 공정 우측 버튼으로 상태를 처리합니다.

대기 → 진행. 작업자명을 입력하면 이력에 기록됩니다.
공정 합격 처리. 완료 시각이 기록되고 다음 공정이 자동 개시됩니다.
불합격 처리. 흐름도의 되돌림 경로대로 이전 공정이 자동 재진행되고 NG 횟수가 누적됩니다.

외주 진행 시 공정 카드 하단의 부품 관리 영역을 이용하세요.

03

외주 부품 관리 (OP40 ~ OP130)

설계~사상·조립(40~130) 공정은 외주업체에서 진행되는 경우가 있어, 공정 카드 하단의 외주 부품 영역에서 부품 단위로 관리합니다.

  • 제목줄을 클릭하면 펼쳐지고, 부품명·치수·가공내용·외주업체를 입력 후 + 추가로 등록합니다.
  • 발주 → 출고 → 입고 버튼을 순서대로 눌러 날짜를 기록합니다. 오늘 날짜가 기본값이며 수정 가능합니다.
  • 날짜가 기록되면 초록색으로 표시되고, 제목줄에 입고완료 건수가 집계됩니다.
  • 모든 기록은 이력 탭에 남습니다.
04

NG 되돌림 경로

NG 처리 시 흐름도의 붉은 회귀선과 동일하게 해당 공정으로 자동 복귀합니다. 되돌림이 지정된 공정은 카드 하단에 경로가 표시됩니다.

OP50 금형설계 승인→ OP40 금형설계 진행
OP140 Try-Out→ OP120 정밀 가공
OP150 고객사 SPL 승인→ OP140 Try-Out
OP160 양산처 Try-Out→ OP140 Try-Out
05

대시보드 — 전체 현황 확인

[대시보드] 탭에서 진행중·완료·NG 누적·전체 금형 수와 금형별 진행률을 확인합니다.

  • 진행률 바 아래에 현재 공정이 표시됩니다. NG가 있으면 NG 공정이 우선 표시됩니다.
  • 카드를 클릭하면 해당 금형의 공정 진행 화면으로 이동합니다.
  • 카드 우측 ✕는 금형과 그 공정·이력을 함께 삭제합니다. 복구되지 않습니다.
06

완료 처리 및 이력 확인

OP180 금형 이관까지 전 공정이 OK가 되면 금형 상태가 완료로 자동 전환됩니다.

  • [이력] 탭에서 등록·시작·OK·NG 전 기록을 최근 200건까지 조회합니다.
  • 기록 항목: 일시 / 금형번호 / 공정코드 / 구분 / 내용 / 작업자.
참고
  • 원본 흐름도의 OP170 중복 항목은 OP170(조립 — 도색·명판·출하검사)과 OP175(영업 — SCRAP BOX·금형이력카드)로 분리했습니다.
  • 공정 마스터(업무 내용·결과물·담당·되돌림 경로)는 DB의 mm_master 테이블에 있습니다. 공정 문구를 바꾸려면 이 테이블을 수정하세요.
  • 데이터는 Supabase에 저장되며 여러 PC에서 같은 현황을 공유합니다.
