설정

마스터 비밀번호 변경

마스터 비밀번호는 로그인과 설정 진입에 함께 사용됩니다. 초기값은 0000입니다.

사원 등록

이름PIN등록일관리

사원 행의 수정을 누르면 이름과 PIN을 바꿀 수 있습니다. 마스터 계정은 목록에 표시되지 않습니다.

금형 제작 공정을 순서대로 설계합니다. ▲▼로 순서를 바꾸고, 수정에서 공정명 · 담당(사내/외주 중복 선택 가능) · 담당부서 · 업무내용 · 출력물 · NG 되돌림을 설정합니다. 변경 내용은 이후 등록되는 금형부터 적용됩니다.

사용안내 — 금형 제작 흐름도 기준 진행 절차

화면 이동은 하단 고정 메뉴(홈 · 진행현황 · ＋등록 · Tryout)와 ☰ 메뉴의 전체 메뉴를 사용합니다. 공정 번호는 흐름도의 OP 번호에서 앞 글자를 뺀 숫자이며, 10 견적 요청부터 180 금형 이관까지 17개 공정으로 관리됩니다.
01

로그인

접속 시 PIN 4자리를 입력합니다. 초기 관리자 PIN은 0000입니다. 로그인한 사람의 이름이 이후 모든 작업의 작업자·작성자로 자동 기록됩니다.

  • 사원 PIN은 메뉴 → 설정에서 등록·수정·삭제합니다. 설정 진입 시 마스터 비밀번호가 필요합니다.
  • 설정 화면의 공정설계 탭에서 공정 순서 · 공정명 · 담당(사내/외주 중복 선택) · 담당부서 · 업무내용 · 출력물 · NG 되돌림을 직접 설계할 수 있습니다. 회사마다 다른 공정 구성에 맞춰 추가·수정·삭제하며, 변경 내용은 이후 등록되는 금형부터 적용됩니다.
  • 설정 화면에서 마스터 비밀번호도 변경할 수 있습니다(현재 비밀번호 확인 후 새 비밀번호 2회 입력). 변경값은 DB에 저장되어 모든 기기에 적용됩니다.
  • 상단 우측의 이름 배지를 누르면 로그아웃됩니다.
02

신규 등록 — 제작 건 개설

하단 ＋등록에서 금형번호와 금형명을 입력합니다. 고객사·제품명·담당자·납기일은 선택 입력입니다.

  • 등록하면 10 ~ 180까지 17개 공정이 자동 생성됩니다.
  • 10 견적 요청은 자동으로 진행이 되고, 나머지는 대기로 둡니다.
  • 등록 직후 진행현황 화면으로 자동 이동합니다.
03

진행현황 — 공정 상태 처리

전체 현황판과 개별 상세 두 가지 방식이 있습니다.

  • 전체 현황판: 세로 = 금형, 가로 = 공정(10~180)의 표로 모든 금형의 진행 상태를 한눈에 봅니다. 대기 · ●진행 · ✓완료 · ✕NG로 구분되며, 계획완료일이 지난 칸은 배경이 붉게 표시됩니다.
  • 칸을 누르면 팝업에서 계획 시작·완료일 입력, 실적 일시, 업무 내용, 진행 메모를 확인하고 진행 / 완료 / NG로 상태를 전환합니다.
  • 왼쪽 금형명을 누르면 해당 금형의 개별 상세로 이동합니다.
  • 개별 상세: 공정 카드가 순서대로 표시되며, 출력물 체크리스트와 부품 관리를 여기서 다룹니다.
대기 → 진행. 시작 시각과 로그인 사용자가 기록됩니다.
공정 합격. 완료 시각이 기록되고 다음 공정이 자동 개시됩니다.
불합격. 지정된 이전 공정이 자동 재진행되고 NG 횟수가 누적됩니다.

공정명 또는 옆의 ?를 누르면 업무 내용 · 결과물 · 되돌림 경로가 팝업으로 열립니다.

색상 구분 — 대기 진행은 주황(미완료), OK는 파랑(완료), NG는 빨강입니다.

04

출력물 체크리스트 — SQ 심사 대응

결과물이 정해진 공정 카드 하단에 「출력물 n/m 작성」 영역이 있습니다. 제목줄을 눌러 펼칩니다.

  • 금형견적서 · 공정검토내역서 · Mill-Sheet · 열처리성적서 · Try-Out Report · 출하검사성적서 · 금형이력카드 등 공정별 결과물이 항목으로 표시됩니다.
  • 작성을 마친 항목에 체크하면 작성일과 작성자가 자동 기록됩니다.
  • 첨부를 눌러 증빙 사진을 등록합니다. 등록된 사진은 눌러서 크게 볼 수 있습니다.
  • 전 항목 작성 시 완비 표시가 붙습니다.
  • 메뉴 → 출력물 점검표에서 금형별 전체 결과물의 작성 여부·작성일·작성자·증빙을 한 장으로 확인하고, 엑셀과 PDF(결재란 포함 A4 양식)로 출력합니다.
05

부품 발주·입출고 관리 (40 ~ 130)

설계부터 사상·조립까지의 공정(40 · 50 · 60 · 80 · 90 · 100 · 120 · 130) 카드 하단 「외주 부품」 영역에서 부품 단위로 관리합니다.

  • ＋ 부품 등록을 누르면 입력란이 세로로 펼쳐집니다. 부품명 · 치수 · 가공내용 · 외주업체를 입력하고 ＋추가로 등록합니다.
  • 한번 등록한 값은 몇 글자만 입력하면 자동완성 목록으로 나타납니다.
  • 발주 → 출고 → 입고 버튼을 순서대로 눌러 날짜를 기록합니다. 오늘 날짜가 기본값이며 수정 가능합니다.
  • 기록된 날짜는 초록색으로 표시되고, 제목줄에 입고완료 건수가 집계됩니다. 전 부품 입고 후 공정을 OK 처리하는 것을 권장합니다.
06

제작계획 — 계획 대비 실적

메뉴 → 제작계획에서 공정별 계획 시작·완료일을 입력해 금형제작 계획을 수립합니다.

  • 각 공정의 완료일 칸을 눌러 달력에서 선택합니다. 달력에는 다른 공정의 계획일이 공정번호로 표시되고, 해당 공정의 날짜는 진하게 강조됩니다. 선행 공정 완료일 이전은 선택할 수 없습니다.
  • 시작일은 이전 공정 완료일로 자동 연결되고 소요일수가 계산됩니다.
  • 연속계획수립: 달력이 열리고 상단에 현재 대상 공정이 표시됩니다. 날짜를 클릭하면 그 공정의 완료일로 지정되고 자동으로 다음 공정으로 넘어가, 계속 클릭만 하면 전 공정 일정이 잡힙니다.
  • 지정된 날짜는 달력에 공정번호로 표시되고, 이전 공정 완료일보다 앞선 날짜는 선택할 수 없습니다. ↩취소로 직전 선택을 되돌리고, 건너뛰기로 해당 공정을 비워두며, 저장을 눌러 한 번에 반영합니다.
  • 계획완료일이 지난 미완료 공정은 지연으로 표시되고 행이 강조됩니다.
  • 엑셀 출력으로 금형제작 계획서(계획 대비 실적)를 내려받습니다.
07

Tryout 작업일지

하단 Tryout에서 Try-Out 진행 내역을 일지로 기록합니다.

  • 작업일 · 금형 · 차수(1차 / 2차 / 3차 / 양산전 / 기타) · 상태(완료 / 진행중 / 이슈 / 보류)를 선택하고, 작업 내용 · 이슈 사항 · 다음 계획을 작성합니다.
  • 사진은 최대 3장 첨부되며, 자동 축소 후 Supabase Storage에 파일로 저장됩니다(DB에는 주소만 보관).
  • 기간 · 금형 · 차수 · 상태로 필터 조회하고, 각 일지의 수정 버튼으로 내용과 사진을 다시 편집합니다.
  • 엑셀은 목록 형태 CSV, PDF는 사진이 포함된 A4 보고서 양식으로 출력됩니다 (인쇄 창에서 'PDF로 저장' 선택).
08

홈 — 전체진행현황 확인

진행중 · 완료 · NG 누적 · 전체 금형 수와 금형별 진행률을 한 화면에서 확인합니다.

  • 진행률 바 아래에 현재 공정이 표시되며, NG가 있으면 NG 공정이 우선 표시됩니다.
  • 카드를 누르면 해당 금형의 진행현황으로 이동합니다.
  • 카드 우측 ✕는 금형과 그 공정 · 부품 · 출력물 · 이력을 함께 삭제합니다. 복구되지 않습니다.
09

이력 · 게시판

180 금형 이관까지 전 공정이 OK가 되면 금형 상태가 완료로 자동 전환됩니다.

  • 이력: 등록 · 시작 · OK · NG · 부품 · 출력물 · Tryout 전 기록을 조회합니다. 기간 · 금형 · 구분 필터, 엑셀(CSV) 출력, 행별 ✕ 삭제를 지원합니다.
  • 기록 항목: 일시 / 금형 / 공정명 / 구분 / 내용 / 작업자.
  • 게시판: 개선·수정 요청사항을 등록하고 상태 뱃지를 눌러 접수 ↔ 완료로 전환합니다.
10

NG 되돌림 경로

NG 처리 시 흐름도의 회귀선과 동일하게 이전 공정으로 자동 복귀하며, 해당 공정이 다시 진행 상태가 됩니다.

50 금형설계 승인→ 40 금형설계 진행
140 Try-Out→ 120 정밀 가공
150 고객사 SPL 승인→ 140 Try-Out
160 양산처 Try-Out→ 140 Try-Out
참고
  • 원본 흐름도의 170 중복 항목은 170(조립 — 도색·명판·출하검사)과 175(영업 — SCRAP BOX·금형이력카드)로 분리했습니다.
  • 원본 흐름도의 70(원자재 및 표준품 입고)과 110(열처리 완료품 입고)은 부품 관리의 입고 기록으로 대체하여 공정에서 제외했습니다.
  • 담당 주체(고객사·사내·외주)는 업체마다 달라 화면에서 구분하지 않습니다. 외주 진행 부품은 05의 부품 관리에 기록하세요.
  • 공정 마스터(업무 내용 · 결과물 · 담당 · 되돌림 경로)는 DB의 mm_master 테이블에 있습니다. 공정 문구 변경은 이 테이블을 수정하세요.
  • 데이터는 Supabase에 저장되며 여러 PC·모바일에서 같은 현황을 공유합니다. 첨부 이미지는 Storage 버킷(mm-photos)에 보관되어 DB 용량에 영향을 주지 않습니다.
